# План вивчення AWS Amplify Gen 1 (V5) через розробку SPA-додатку для пошуку співробітників

## Мета

Створити SPA-додаток на Vue 3 з використанням Primevue 3.5, Amplify Gen 1 (V5), Vite, Typescript 4.5. Додаток — база для пошуку співробітників з CRUD-операціями, фільтрацією та інтеграцією з AWS через Amplify. План орієнтований на новачків у Amplify, AWS, GraphQL, Primevue.

## 1. Підготовка середовища

- [x] Встановити Node.js, npm, Git
- [x] Ознайомитись з основами AWS (реєстрація, консоль)
- [x] Встановити AWS CLI та налаштувати профіль
- [x] Встановити Amplify CLI (`npm install -g @aws-amplify/cli`)
- [x] Ознайомитись з базовими командами Amplify CLI

## 2. Створення фронтенду

- [x] Ініціалізувати проект Vite з Vue 3 та Typescript
- [x] Встановити Primevue 3.5 та Primeicons
- [ ] Додати базову структуру SPA (App.vue, компоненти)
- [ ] Додати базову верстку: список співробітників, поле пошуку, кнопки CRUD

## 3. Підключення Amplify

- [x] Ініціалізувати Amplify у проекті (`amplify init`)
- [ ] Додати бекенд (GraphQL API) через Amplify (`amplify add api`)
- [ ] Ознайомитись з основами GraphQL (типи, запити, мутації)
- [ ] Створити GraphQL-схему для співробітників (id, name, position, isFavorite)
- [ ] Налаштувати seed-дані (5 співробітників при першому запуску)
- [ ] Деплоїти бекенд на AWS (`amplify push`)

## 4. Інтеграція фронтенду з бекендом

- [ ] Встановити AWS Amplify JS бібліотеки
- [ ] Налаштувати підключення до бекенду у фронтенді
- [ ] Реалізувати отримання списку співробітників з бекенду
- [ ] Реалізувати додавання нового співробітника
- [ ] Реалізувати редагування співробітника
- [ ] Реалізувати видалення співробітника
- [ ] Реалізувати відмітку "обраного"
- [ ] Реалізувати пошук за ім’ям/посадою
- [ ] Реалізувати фільтрацію лише обраних

## 5. (Опціонально) Додати авторизацію

- [ ] Додати Auth через Amplify (`amplify add auth`)
